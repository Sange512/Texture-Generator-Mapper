# 主工作流模型与节点配置

以下配置以本仓库 `active_workflow_api.json` 为准。ComfyUI 需要独立安装和启动，主程序默认通过 `http://127.0.0.1:8188` 连接。

## 模型文件

| ComfyUI 目录 | 工作流中配置的文件名 |
| --- | --- |
| `models/diffusion_models/` | `qwen_image_edit_2509_fp8_e4m3fn.safetensors` |
| `models/text_encoders/` | `qwen_2.5_vl_7b_fp8_scaled.safetensors` |
| `models/vae/` | `qwen_image_vae.safetensors` |
| `models/loras/` | `8步加速Qwen-Image-Lightning-8steps-V2.0-bf16_V2.0.safetensors` |

这些是当前工作流中的精确名称。若下载后的文件名或子目录不同，请修改 API 工作流中 1、2、3、23 号节点对应字段，使其与 ComfyUI 模型列表一致。不要仅修改 `workflow/` 里的备份。

89 号 `RMBG` 节点使用 `RMBG-2.0`，其模型下载和存放位置按所安装的 RMBG 节点包说明配置。仓库不附带以上权重。

## 节点要求

当前工作流除 ComfyUI 核心节点外，还使用 `ImageResize+` 和 `RMBG`。请在 ComfyUI 中通过节点管理器查找并安装提供这些类名的扩展，再重启 ComfyUI。还需确保当前 ComfyUI 支持 `TextEncodeQwenImageEditPlus`、`TextEncodeQwenImageEdit` 和 `CFGNorm` 等工作流节点。

主工作流没有使用 ControlNet 或 DepthAnything 预处理节点，不需要为主流程额外安装它们。`workflow/` 中的其他实验工作流有各自的依赖。

## 输入输出绑定

- 10 号 `LoadImage`：前端当前视角白模截图。
- 11 号 `LoadImage`：参考图，或多张参考图合成的参考板。
- 26 号 `KSampler`：采样种子，当前配置为 8 步。
- 89 号 `RMBG`：透明背景结果。
- 服务提交时追加 900 号 `SaveImage`，用于从 ComfyUI 历史记录获取结果。

10、11 号节点中保存的旧图片名称是占位值，生成任务时会自动替换，无需另找同名图片。

## Python 依赖与验证

主程序：`python -m pip install -r requirements.txt`，依赖 Pillow 和 requests。

独立对齐工具分别使用各自目录中的 `requirements.txt`。Marigold 工具依赖见该工具的 README。

启动 ComfyUI 与本地服务后，查看界面连接状态和工作流依赖提示，再执行一次生成确认 GPU 环境可用。运行速度和显存需求取决于 ComfyUI 环境及硬件，本仓库没有声明通用的最低显存或性能基准。
